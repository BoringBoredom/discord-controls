# Discord Controls

Chrome extension that registers two global keyboard shortcuts that click Discord's mute or deafen controls in the most recently accessed Discord tab or PWA window.

## Install

- Download and unzip Discord Controls.
- Open `chrome://extensions` / `brave://extensions` / `edge://extensions`.
- Enable `Developer mode`.
- Click `Load unpacked`.
- Select the Discord Controls folder.
- Click `Keyboard shortcuts`.
- Assign global shortcuts for `Toggle Mute` and `Toggle Deafen`.
